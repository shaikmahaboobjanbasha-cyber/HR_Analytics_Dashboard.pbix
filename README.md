# HR Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI to analyse employee data and uncover meaningful insights related to workforce demographics, salaries, performance, departments, and company growth.

## Project Objectives
- Analyse employee distribution across departments.
- Understand gender distribution within departments.
- Explore employee age distribution.
- Analyse minimum, maximum, and average salaries by department.
- Identify top earners across countries.
- Examine employee performance ratings.
- Track company growth trends.
- Filter employees based on starting letters.
- Analyse the relationship between performance and salary.
- Compare HR metrics between India and New Zealand.

## Key Analysis
1. Department-wise employee count
2. Gender distribution by department
3. Employee age distribution
4. Salary analysis by department
5. Top earners by country
6. Performance distribution
7. Company growth trend
8. Employee name filtering
9. Performance vs. salary analysis
10. India vs. New Zealand comparison
